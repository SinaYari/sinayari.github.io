# Sina Yari — GitHub Pages Portfolio

This folder is ready to publish as a GitHub Pages site.

## Profile photo
The HTML expects a file named `profile.jpg` in this same folder. Your existing GitHub Pages repository already uses `profile.jpg`, so keep that file when replacing the rest of the site. If needed, save your provided portrait as `profile.jpg`.

## Publish
Copy these files into the root of the `sinayari.github.io` repository:

- `index.html`
- `styles.css`
- `script.js`
- `resume.pdf`
- `profile.jpg` (keep your current file or replace it with your supplied photo)

Then commit and push to the `main` branch.
